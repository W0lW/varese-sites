# Template 3D

Raccolta di riferimento per template di siti web 3D interattivi.

## Repository completo: Dioramas

Il progetto open-source Dioramas contiene 20 esempi di landing page 3D complete, motore Three.js, scene e modelli 3D ottimizzati.

- Repository originale: https://github.com/blendi-remade/dioramas
- Archivio ZIP completo: https://github.com/blendi-remade/dioramas/archive/refs/heads/main.zip
- Licenza codice: MIT
- Modelli e immagini generati: CC BY 4.0 (attribuzione richiesta)
- Licenze dipendenze: consultare THIRD_PARTY_NOTICES.md

## Esempi interessanti

- Nightshift Motor Co. — moto in una scena notturna, utile come riferimento per siti automotive
- Velocity Lab — prodotto con visualizzazione interattiva
- Monolith — architettura e casa
- Nocturne — prodotto premium con animazione 3D
- Hangar Nine — mech interattivo

## Nota sul contenuto

Questa cartella contiene la documentazione e i riferimenti al progetto originale; non contiene ancora l'intero archivio Dioramas né i suoi modelli 3D. L'archivio completo è circa 330 MB: va importato in blocco tramite Git/ZIP, non ricreato file per file tramite l'API GitHub.

Per usare il progetto localmente, scaricare lo ZIP dal link sopra, estrarlo e seguire le istruzioni del README originale (installazione dipendenze e avvio con `npm run dev`). Le funzionalità di generazione di nuovi modelli tramite servizi AI esterni possono avere costi; gli esempi già inclusi sono scaricabili gratuitamente.
