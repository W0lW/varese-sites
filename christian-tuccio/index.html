Apri il repository ufficiale ↗

Il codice sorgente è collegato anche in questa repository come Git submodule. BookCars è un'applicazione full-stack: il repository non equivale a una demo online e per eseguirla servono backend, database e configurazione. Non è attualmente pubblicata come sito funzionante su GitHub Pages.
