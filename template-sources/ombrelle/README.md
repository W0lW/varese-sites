Template gratuito originale di 8B, copiato qui per anteprima separata su GitHub Pages.

ATTENZIONE: è una demo dimostrativa con dati fittizi in inglese (indirizzo, telefono, orari e prenotazione). Il modulo di prenotazione è solo dimostrativo e non invia prenotazioni. Non è il sito ufficiale di alcun ristorante e non va usato come tale senza personalizzazione e verifica dei contenuti.
