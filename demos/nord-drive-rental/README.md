# NORD DRIVE — car rental demo

Portfolio concept for a premium car-rental web app.

## Included
- Responsive landing page and vehicle cards
- Quote request form: vehicle/category, transmission, pickup/return dates and location, driver age, contact details and notes
- WhatsApp handoff with a prefilled quote request
- Cookie preference banner (accept/reject stored locally)
- Vehicle photography and a muted looping hero video
- Accessible labels, date validation, reduced-motion support

## Demo notes
This is a front-end-only portfolio concept. It does not create real reservations, process payments, store leads on a server, or represent a real rental company. Replace the demo WhatsApp number (`393331234567`), brand, vehicle data, prices, images and legal copy before any real-world use.
