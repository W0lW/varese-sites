[ 02 ] — Approach

Six rules we
do not break.

  1. 01COL 01–04

    Measure twice.

    Every dimension is a decision. We make each one on purpose, then defend it.

  2. 02COL 05–08

    The grid is a promise.

    A system other people can build on without calling us first.

  3. 03COL 09–12

    Subtract until it breaks.

    Then add back the single part that was quietly holding it up.

  4. 04COL 01–04

    Material tells the truth.

    Concrete reads as concrete; steel behaves as steel. No costumes.

  5. 05COL 05–08

    The joint is the design.

    Detail is not decoration; it is where the thinking becomes visible.

  6. 06COL 09–12

    Build to be read.

    A structure should explain itself before the caption does.
