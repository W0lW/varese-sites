# Varese Sites

Raccolta di demo web personalizzate per attività della provincia di Varese.

## Struttura
- `index.html`: catalogo delle demo.
- `sites/<slug>/index.html`: sito indipendente per ciascuna attività.
- Ogni demo è un concept commerciale e non rappresenta un sito ufficiale dell'attività finché non viene approvato dal titolare.

## Principi
- Responsive, accessibile e con rispetto di `prefers-reduced-motion`.
- Animazioni leggere e interazioni senza bloccare la navigazione.
- Dati pubblici da verificare prima della pubblicazione.
- Nessuna recensione, certificazione, prezzo o promessa inventata.

## Anteprima locale
Apri `index.html` nel browser oppure pubblica la repository con GitHub Pages.
